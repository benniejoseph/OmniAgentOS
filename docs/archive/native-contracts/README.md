# Native contract retirement archive

`v47/` retains the complete original native contract documents byte for byte. They are source-controlled audit artifacts outside the public serving path. The native contract generator verifies all four original SHA-256 values before generating the narrowly withdrawn v47 compatibility publication.

Contract v48 retires the CRM workspace. The supported v47 publication removes only its operations, CRM schemas, and customer push target while preserving all other v47 operation and schema meanings. See `docs/mobile-api.md` for the compatibility exception.
