# Native v30 package refresh — 1.23.8+43

Contract, dependency, analysis, Flutter test, macOS policy, and package
verification checks have passed. The signed macOS package was independently
extracted and verified, and the owner-signed Android APK was verified on
3 October 2026. Installation and real-device smoke checks have not been performed.

This release packages the existing native contract v30 client and macOS helpers
from main revision `a06aa78b`, with v29 compatibility retained. The source change
is the Flutter version bump from `1.23.7+42` to `1.23.8+43`; it does not change
application behavior, the API, the database, or the planned UI redesign.

The refreshed macOS helper includes the target checks, restricted-application
and browser-page checks, screenshot exclusions, covered-click refusal, and
interrupted-typing handling documented under the continuous native Computer Use
release in [deployment.md](../deployment.md#continuous-native-computer-use-release).
Those checks require the rebuilt app; a server deployment alone cannot update
the installed native helper.

## Distribution and live validation

macOS packaging is configured to use the existing owner-only signing identity
and exact frozen v2 credential broker. It is intended for the owner's Mac, is not notarized, and
does not support APNs. This refresh does not rotate signing keys, reset TCC,
reprovision the broker, grant OS permissions, or install or launch the app.

Installation and a real-device smoke check remain separate release steps. Verify
the signed packaged app's version and designated requirement before replacing
the installed app; retain the existing installation and prior release artifacts
for rollback. After installation, confirm authenticated native v30 attestation,
normal conversation and voice behavior, and the approved local-computer flows.
An unsigned Xcode build product is not the installation artifact.

No iOS distributable or Apple-notarized macOS release is produced by this
owner-local release process. Android installation and hardware behavior require
a separate real-device check.
